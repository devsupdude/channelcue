  1. Open Google Cloud Console and create or select a project.
  2. Go to APIs & Services, then enable YouTube Data API v3.
  3. Go to Credentials and create an OAuth client ID.
  4. Choose Web application as the application type.
  5. Add the JavaScript origin and redirect URI below.
  6. Copy the client ID and client secret into this form, then save.
